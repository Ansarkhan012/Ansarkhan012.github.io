# Ansar Games brand kit

- `ansar-games-logo-transparent.png`: transparent AG master, website aur design use ke liye.
- `ansar-games-developer-icon-512.png`: 512 × 512, 32-bit RGBA PNG, opaque ivory background. Play Console ke developer profile icon ke liye export.
- `ansar-games-developer-icon-1024.png`: high-resolution export.

AG mark orange A, navy G aur yellow detail ko jorta hai. Website par is ke saath Outfit typeface mein **Ansar Games** wordmark use hota hai. Colours: orange #ff4b16, navy #0b1d3b, ivory #fffaf2, yellow #ffd325.

Play Console mein developer profile ki branding par 512 file upload karein. Game-specific app icons apni pehchan rakhte hain. Account mein upload abhi nahi kiya gaya.

Google ki current developer-icon requirement: [512 × 512, 32-bit PNG](https://support.google.com/googleplay/android-developer/answer/9873827?hl=en).

Logo built-in ImageGen se approved website option 2 ke reference par banaya. Resizing, canvas export aur WebP compression asset preparation mein hue. Yeh raster exports hain; vector master deliver nahi hua.
